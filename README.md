Website estático desenvolvido como parte da disciplina Laboratório de Programação de Computadores I da Universidade Estadual do Amazonas (UEA), para apresentação do jogo Monster Mania.

---

## Sobre o Projeto

O site apresenta o jogo Monster Mania, um projeto em que o jogador deve sobreviver a ondas de inimigos, derrotando goblins cada vez mais perigosos e coletando power-ups para aumentar suas habilidades.

- Descrição do gameplay e mecânicas do jogo.
- Apresentação dos inimigos e suas características.
- Lista de power-ups disponíveis.
- Links para o repositório e vídeo demonstrativo.
- Créditos da equipe e fontes de áudio.

---

## Sobre o Jogo

Em Monster Mania, o objetivo é simples: ser o último monstro de pé.

- Sobreviva a ondas infinitas de goblins.
- Escolha power-ups estrategicamente para se manter vivo.
- Enfrente diferentes tipos de inimigos com habilidades únicas.
